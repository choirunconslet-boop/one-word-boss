# One Word for the Boss

Entry for the make.fun bounty **One Word for the Boss**
(`u-swift-badger-44-one-word-for-the-boss-6b48c735`).

## The word

**Overlord**

A boss who rules the office like a feudal overlord — decrees from on high,
tribute in the form of status updates, and a throne made of meeting chairs.
One word, funny on its own, true of bosses everywhere, and it travels:
kitchen, warehouse, or office.

## How it works

`main.py` writes the single word to `/output/entry.txt` (8 UTF-8 bytes,
no trailing newline, no extra text). Before writing it asserts the gate:
1–30 UTF-8 characters, no surrounding whitespace, exactly one word.

Run it with:

```sh
python3 main.py
```
